# pSEO Engineering Skills & Rules

## Rule: UX-First pSEO Generation
Each generated page must pass a value-test for the user. We avoid "thin content" purely for bots. 

### Guidelines:
1. **Utility Over Quantity**: Do not generate a page if the product data is insufficient (e.g., missing price and description).
2. **Dynamic Uniqueness**: Every page must have a unique introduction and conclusion (min. 30% variation) to provide specific context for the category/ingredient/problem combination.
3. **Data Accuracy**: Affiliate prices must be refreshed at least once every 24 hours.
4. **Rich Interactivity**: Include comparison tables and "Price Tracker" modules on every landing page.
5. **Schema Correctness**: Always implement `Product`, `Review` (if available), and `FAQPage` JSON-LD.

## Technical Skills
- **Supabase Data Mapping**: Expert understanding of how `products_ceneo` maps to UI components.
- **Matrix Generation**: Ability to expand keyword tiers based on market demand (Kategoria + Składnik + Cel).
- **Vibe Coding**: Creating premium, high-converting React layouts that don't look like typical SEO spam.
